## GitHub Pages

The static project page lives in [`docs/`](docs/). In the repository settings, select **Pages → Deploy from a branch → `main` → `/docs`** and save. See [GitHub Pages setup](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

This repository contains the project website, not the token program. The website does not connect to wallets or ask users to sign transactions. Memecoins are speculative and can lose their entire value.
